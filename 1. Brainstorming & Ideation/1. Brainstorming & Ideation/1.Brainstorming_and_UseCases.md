# Brainstorming Insights & Use Cases

## 1. Solution Comparison

| Mechanism | Layer | Security Level | Why Chosen / Rejected |
| :--- | :--- | :--- | :--- |
| **UI Policy** | Client (Browser) | Low | Can be bypassed via List views and REST APIs. |
| **Data Policy** | Server & UI | Medium | Limited capability for dynamic multi-condition scripts. |
| **Scripted ACL** | Database (Server) | **High (Enterprise Standard)** | **Selected:** Cannot be bypassed by UI, List, or API calls. |

## 2. Core Business Use Cases
- **Case 1 (Post-Close Lock):** Closed incident records must remain immutable to all non-admin agents.
- **Case 2 (Admin Override):** System administrators must be able to perform emergency data corrections.
- **Case 3 (Active Ticket Flow):** Assignees can modify records while ticket status is New, In Progress, or On Hold.
