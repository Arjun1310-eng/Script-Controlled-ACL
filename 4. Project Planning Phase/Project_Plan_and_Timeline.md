# Phase 4: Project Planning & Timeline

## 1. Project Work Breakdown Structure (WBS)
- **Work Package 1: Environment Readiness**
  - Personal Developer Instance (PDI) request and activation
  - Elevating session roles to `security_admin`
- **Work Package 2: Analysis & Logic Formulation**
  - Evaluating standard Incident states (`New`, `In Progress`, `Resolved`, `Closed`)
  - Constructing boolean logic trees for the `answer` variable
- **Work Package 3: Development & Configuration**
  - Creating record-level `write` ACL rule on `Incident [incident]`
  - Coding conditional JavaScript execution script
- **Work Package 4: Testing & Verification**
  - Impersonating non-admin ITIL users
  - Testing active vs closed state edit restrictions
- **Work Package 5: Final Submission & Documentation**
  - Compiling test reports and screenshots
  - Pushing full repository to GitHub
